# Tommy's Barber Shop

Production-ready static website for Tommy's Barber Shop, Knaresborough.

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then save.
4. The site will be available at:

   https://probuilderoffical.github.io/tommysbarber/

## Stack

- Semantic HTML
- Responsive CSS
- Vanilla JavaScript
- No build step or external framework required
- Mobile navigation, reduced-motion support, SEO/Open Graph metadata and LocalBusiness structured data

## Business data

The site uses the shop's public booking information for services, prices, hours, team bios and booking links. Live availability remains on the Nearcut booking portal.

## Images

Public shop photography is loaded from the business's Nearcut CDN so the repository stays lightweight.
